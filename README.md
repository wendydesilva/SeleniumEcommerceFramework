# 📌 Project Overview

This project is a professional Selenium automation framework developed for testing the https://www.saucedemo.com/ ecommerce web application.  
It demonstrates modern QA automation practices including:

✅ Page Object Model (POM)  
✅ Reusable Utilities  
✅ TestNG Execution  
✅ Automated Reporting  
✅ Scalable Framework Structure  
✅ Screenshot Capture on Failures  
✅ Clean & Maintainable Code

# 🚀 Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/wendydesilva/SeleniumEcommerceFramework.git
```

---

## 2️⃣ Open the Project

Import the project as a **Maven Project** in IntelliJ IDEA or Eclipse.

---

## 3️⃣ Install Dependencies

```bash
mvn clean install
```

---

## 4️⃣ Run the Tests

```bash
mvn test
```

Or execute the `testng.xml` file directly from the IDE.
